# Superpowers Workflow

Before any creative work, bug fixing, or development task, invoke and adhere to the relevant skill in `.agents/skills/`:
- **Creative work / features**: use `brainstorming` before implementing.
- **Planning**: use `writing-plans` to break work into small tasks.
- **Execution**: use `subagent-driven-development` or `executing-plans`.
- **Implementation / TDD**: use `test-driven-development`.
- **Debugging**: use `systematic-debugging`.
- **Review & Verification**: use `requesting-code-review`, `receiving-code-review`, and `verification-before-completion`.
- **Branch completion**: use `finishing-a-development-branch`.
- **Blender / Technical Art**: use `blender-technical-art` for 3D modeling, procedural generation, shading, numeric verification ladders, hard quality gates, and machine-readable verdicts.
- **Custom skills**: use `writing-skills`.

For tool mappings and guidelines, refer to [.agents/skills/using-superpowers/SKILL.md](file:///e:/Claudio/.agents/skills/using-superpowers/SKILL.md).
